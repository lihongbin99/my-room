# 同步书籍与添加新书

读书记录唯一维护处是飞书多维表格（用户维护），本项目从飞书单向同步。

## 同步流程

1. 跑 `node tools/sync-books.mjs`：重写 `booksData.js`（日期/状态/评分以飞书为准，
   pages/height/color 本地保留）；新书自动下载封面到 `public/books/`、算封面主色调，
   pages/height 写 null 并打印清单。
2. 对清单里的新书，按下面「页数与高度」联网查后手工补进 booksData.js（重跑同步不会冲掉）。
3. `node tools/upload-oss.mjs` 传新封面（运行时封面从 OSS 加载，只存本地看不到）。
4. `git diff` 核对后提交。

## 页数与高度的获取

1. **页数**：WebFetch 抓 `https://book.douban.com/isbn/<ISBN>/`（自动跳版本页，实测无反爬）。
   取「页数」，顺便核对书名/作者/出版社。现有数据口径与豆瓣一致，以它为准。
2. **高度**：WebSearch「`<ISBN> 开本 尺寸`」，从电商/百科结果拿开本换算；
   若页面直接给精确尺寸（如 21×14.5cm）优先用长边。

## 开本 → height（mm，取长边）

| 开本 | height |
|---|---|
| 32开 / 大32开 | 210 |
| 正32开（明确标注） | 184 |
| 16开 | 260 |
| 大16开 | 285 |
| 查不到 | 210 兜底 |

注意：电商标「32开」多不严谨，大陆文学平装实际多为 210（A5），默认按 210。
页数各电商有出入，以 ISBN 精确匹配的豆瓣页为准。

## 其他字段

- `cover` / `color`：同步脚本自动处理（封面来自飞书附件，color 取 sharp 主色调，不合适可手调）。
- 宽度/厚度不用查：运行时由高度和页数推算（`Bookshelf.bookDims()`）。

## 调研结论（2026-08，为什么这么定）

- 豆瓣：页数最全最准，但信息栏无开本/尺寸字段。
- Open Library API：免费有页数，但国内版本有缺失（骆驼祥子江苏文艺版无记录），
  `physical_dimensions` 对中文书全空。
- Google Books：中文覆盖弱，本环境配额为 0。
- 当当 DNS 不通；苏宁详情页可抓到开本。
- 国图 OPAC / WorldCat 有权威厘米数但网络不通/被拦。
- 付费 ISBN API 不值（增量一次一本）。
- 不写自动化脚本：反爬对脚本更苛刻，维护不划算。
