# WinXP

> Fork 自 [ShizukuIchi/winXP](https://github.com/ShizukuIchi/winXP)（MIT 协议，作者 ShizukuIchi），
> 用于 my-room 3D 房间作品集的显示器屏幕。改动：homepage 改为 /xp/、构建产物输出到
> ../public/xp/（cross-env BUILD_PATH）、禁用 CRA eslint 插件。
> 构建：`npm run build:xp`（在仓库根目录）或本目录 `npm install --legacy-peer-deps && npm run build`。

🏁 Web based Windows XP desktop recreation.

Features:

- Drag and resize, minimize, maximize windows
- Open applications from desktop icons or start menu
- Minesweeper, Internet Explorer, My Computer, Notepad, Winamp, Paint
- Power off menu
